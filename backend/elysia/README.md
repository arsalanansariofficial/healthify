### Features

- Dashboards for Users
- Tasks Search & Filtering
- Fully typed with TypeScript

### Requirements

- Node.js 20+
- Bun package manager
- A configured .env file (see .env.example)

### Installation

```bash
bun i
```

### Development

```bash
bun run dev
```

### Environment Variables

Use the .env.example file to configure:

- Database
