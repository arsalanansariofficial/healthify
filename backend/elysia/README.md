### Features

- Automatic account linking
- Cookie cache for low response time
- OAuth using GitHub
- Email verification
- OpenAPI for route documentation
- Username login and signup
- Test utilities for authenticated tests
- Multiple sessions
- Anonymous login
- Admin accounts
- Login with Magic Link
- Two-factor authentication
- Phone number login and signup
- Organizations and teams with dynamic access control

### Requirements

- Node.js 20+
- Bun package manager
- A configured .env file (see .env.example)

### Installation

```bash
bun i
```

### Development

```bash
bun dev
```
